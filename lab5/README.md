## Выбор варианта

Номер варианта: **N = 24**.

Вид представления графа определяется формулой `(N % 3) + 1`:

```
(24 % 3) + 1 = 0 + 1 = 1  →  матрица смежности
```

Алгоритм определяется формулой `(N % 5) + 1`:

```
(24 % 5) + 1 = 4 + 1 = 5  →  алгоритм Флойда — Уоршелла
```

Итог:
- **Представление графа:** матрица смежности
- **Реализуемый алгоритм:** алгоритм Флойда — Уоршелла
- **Назначение алгоритма:** поиск кратчайших путей между всеми парами вершин взвешенного графа

## Формулировка задания

Написать программу, которая выполняет поиск кратчайших путей между всеми парами вершин взвешенного графа с помощью алгоритма Флойда — Уоршелла.

Граф вводится в виде матрицы смежности. В матрице значение элемента означает вес ребра между вершинами; отсутствие ребра обозначается специальным значением `-1`, которое в программе заменяется на бесконечность `INF`. На главной диагонали должны стоять нули (расстояние от вершины до самой себя равно 0).

Программа считывает количество вершин графа, затем матрицу смежности, выполняет алгоритм Флойда — Уоршелла и выводит итоговую матрицу кратчайших расстояний. Если путь между какими-либо вершинами отсутствует, выводится `INF`.

Дополнительно реализована проверка на отрицательный цикл: если после выполнения алгоритма на главной диагонали матрицы расстояний есть отрицательное значение, программа выводит сообщение о наличии отрицательного цикла.

## Алгоритм Флойда — Уоршелла

### Идея

Алгоритм находит кратчайшие пути между всеми парами вершин ориентированного взвешенного графа. Он работает с матрицей расстояний `dist[i][j]` и последовательно «разрешает» использовать вершины `0, 1, …, n−1` как промежуточные. На итерации `k` пересчитываются все пары `(i, j)`: если путь `i → k → j` короче ранее известного `i → j`, расстояние обновляется.

После `n` итераций в `dist[i][j]` хранится длина кратчайшего пути из `i` в `j` с возможностью использовать любую из `n` вершин в качестве промежуточной — то есть фактический кратчайший путь.

### Псевдокод

```
для k от 0 до n-1:
    для i от 0 до n-1:
        для j от 0 до n-1:
            если dist[i][k] + dist[k][j] < dist[i][j]:
                dist[i][j] := dist[i][k] + dist[k][j]
```

### Сложность

- Время: **O(V³)**, где V — число вершин
- Память: **O(V²)** (хранится матрица расстояний)

### Обнаружение отрицательного цикла

Если в графе есть цикл с суммарным отрицательным весом, проходящий через вершину `i`, то после прогона алгоритма `dist[i][i]` станет отрицательным. Достаточно проверить главную диагональ.

### Основные функции (`floyd_warshall.c`)

- `fw_read_matrix(in, &n, &dist)` — читает количество вершин и матрицу смежности; на диагонали ставит `0`, значение `-1` заменяет на константу `INF`, возвращает 0 при ошибке формата.
- `fw_run(n, dist)` — выполняет алгоритм Флойда — Уоршелла на месте. Релаксация пропускается, если промежуточное значение уже равно `INF`, что предотвращает арифметическое переполнение.
- `fw_has_negative_cycle(n, dist)` — проверяет главную диагональ матрицы расстояний на наличие отрицательного значения.
- `fw_print_matrix(out, n, dist)` — печатает матрицу; недостижимые пары выводятся как `INF`.
- `main(argc, argv)` — ввод-вывод (см. ниже).

Внутреннее представление веса — `long long`. Константа отсутствия пути:

```c
#define INF (LLONG_MAX / 4)
```

Делитель 4 даёт запас от переполнения при сложении двух «бесконечностей» — даже если такая сумма случайно посчитается, она не зацикливается в отрицательное.

## Формат входных и выходных данных

### Вход

```
N                   — количество вершин (целое > 0)
N×N значений        — матрица смежности, разделители — пробелы или переводы строк
```

В матрице:
- `0` на главной диагонали (программа в любом случае принудительно ставит 0);
- вес ребра от вершины `i` к вершине `j` для существующих рёбер;
- `-1` для отсутствующих рёбер.

### Выход

В случае обычного графа:

```
Матрица кратчайших расстояний:
<N строк по N значений>
```

Недостижимые пары — `INF`.

В случае обнаружения отрицательного цикла:

```
В графе обнаружен отрицательный цикл
```

## Примеры работы

### Пример 1 — `input_small.txt` (4 вершины)

Граф (ориентированный):

```
0 → 1 (3)    0 → 3 (7)
1 → 0 (8)    1 → 2 (2)
2 → 0 (5)    2 → 3 (1)
3 → 0 (2)
```

**Вход:**

```
4
0 3 -1 7
8 0 2 -1
5 -1 0 1
2 -1 -1 0
```

**Выход:**

```
Матрица кратчайших расстояний:
0 3 5 6
5 0 2 3
3 6 0 1
2 5 7 0
```

Например, расстояние `1 → 0` равно `5` благодаря пути `1 → 2 → 3 → 0` (2 + 1 + 2 = 5), а не прямому ребру `1 → 0` весом 8.

### Пример 2 — `input.txt` (9 вершин)

Классический неориентированный взвешенный граф из CLRS («Introduction to Algorithms»). Все пары вершин достижимы, поэтому `INF` в выводе быть не должно.

### Пример 3 — отрицательный цикл

Граф с циклом `0 → 1 → 2 → 0` суммарного веса `1 + (−3) + (−3) = −5`:

**Вход:**

```
3
0 1 -1
-1 0 -3
-3 -1 0
```

(рёбра: `0→1: 1`, `1→2: −3`, `2→0: −3`. Заметим, что значение `-1` в матрице зарезервировано под «отсутствие ребра», поэтому отрицательные веса задаются числами меньше `−1`.)

**Выход:**

```
В графе обнаружен отрицательный цикл
```

После прогона алгоритма `dist[0][0]` становится отрицательным, что и используется как индикатор наличия цикла.
